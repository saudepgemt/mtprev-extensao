AJUSTES:
- O botão Configurações envia MTPREV_OPEN_OPTIONS ao service worker em vez de chamar openOptionsPage no content script.

- O botão Usar endereço-base conhecido preenche o domínio autorizado (pode exigir caminho/chave do administrador).
- Notificações: escolher Gmail API + OAuth (automático) OU Aplicativo de e-mail (manual, sem OAuth).
- No modo manual, Acompanhamento Especial > dados de cada processo oferece Preparar aviso no aplicativo de e-mail.
  A MTPrev NÃO envia em segundo plano; abre um RASCUNHO que depende da confirmação do usuário no cliente de e-mail.
- O modo manual não usa o token OAuth, embora o manifesto deste pacote mantenha OAuth para permitir o modo automático opcional.

IMPORTANTE:
- Não armazene credenciais SMTP, tokens, senhas ou chaves privadas no JavaScript nem no manifesto.
- Envio 100% automático sem OAuth na EXTENSÃO exige um backend de e-mail institucional autenticado.
  Esse backend NÃO está incluído neste pacote.
- No modo manual, o programa de e-mail precisa ter uma conta configurada. Revise o remetente e o sigilo.
- O teste MCP local não acessa os processos: valida apenas a conexão com o servidor externo.
- O módulo Autos/PDF e algumas rotinas legadas continuam com testes pendentes; não publicar na Chrome Web Store sem revisão.
